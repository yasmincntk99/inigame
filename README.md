# Gaameai – Tiga Jalur

Game MOBA 2D ringan (HTML5 canvas, satu file, tanpa library). Aset dan kode orisinal.

Cara main: ketuk tanah untuk jalan, ketuk musuh untuk serang, tombol Q (atau keyboard Q) untuk jurus area. Hancurkan markas merah.

LOD: unit jauh dari kamera diproses lebih jarang dan digambar sebagai titik; unit di luar layar tidak digambar.

Jalankan: buka `index.html` di browser, atau aktifkan GitHub Pages.
